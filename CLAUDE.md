# web-studio-starter

GitHub template for new web-studio client sites (Next.js, TypeScript, Vercel, web-studio-kit).

## Language rule (mandatory)

Everything in this repository is written in **English**: code, identifiers, comments, commit messages, README and all other docs, PR descriptions, issues.

The only exception is user-facing copy on client websites, which may be Polish. Every site should still offer a language switch with an English version.
