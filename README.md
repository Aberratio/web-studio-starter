# web-studio-starter

Template for a new client website. Next.js + TypeScript, with `web-studio-kit` wired in and ready to deploy on Vercel.

## New client site

```sh
gh repo create aberratio/<client>-site --template aberratio/web-studio-starter --public --clone
```

## Conventions

- Code and docs in English.
- UI copy may be Polish, with an English language switch.
